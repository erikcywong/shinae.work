A stock movement with receipts — not a spreadsheet with opinions. 改一次库存，留一条证据链：不是一张有意见的表格。

The same kernel that runs the carbon ledger now runs lots: green coffee leaves FIFO, roasted coffee leaves FEFO, an expired or quarantined lot can never be picked, and every quantity change passes plan → critic → dry-run → a second person → execute → verify, with each step hashed into a chain. 同一个内核跑第二个垂直域：绿咖啡 FIFO、熟豆 FEFO，过期与隔离批次永不被选中； 每次改数量都要过计划 → Critic → dry-run → 第二个人 → 执行 → 核验，每一步都进哈希链。

The loop why it is a gate, not a chat

submit ──► awaiting_approval ──approve──► done ──verify──► reflect
   │                │
   │                └──reject──► rejected
   └─critic fails──► blocked        (no movement, ever)

plan.created → critic.evaluated → dryrun.computed
            → approval.requested ─► approval.granted | rejected
            → executed ─► verified            (+ four_eyes.waived on --force)

PLANNER

Pure functions of the store: allocation order, quantities, shortfall, excluded lots.

计划是数据库的纯函数：分配顺序、数量、缺口、被排除的批次都能重放。

CRITIC

Deterministic checks: SKU exists, unit is kg, stock suffices, lots are released and not expired.

确定性校验：SKU、单位、库存、批次状态、赏味期，逐条给理由。

FOUR EYES

The requester cannot approve. A forced approval is written into the hash chain, not hidden.

申请人不能批准；强行批准会写进哈希链，不会消失。

Hard rules

  • Green leaves FIFO, roasted leaves FEFO. · 绿咖啡按入库日 FIFO，熟豆按赏味期 FEFO。
  • Expired, quarantined or empty lots are never picked — the critic says which and why. · 过期、隔离、空批次永不被选中；Critic 会指出是哪个、为什么。
  • wh_lot.qty_kg must equal the sum of wh_move deltas. · 批次缓存数量必须等于 move 账本之和。
  • One idempotency key per movement; approving twice cannot deduct twice. · 每个动作一个幂等键；重复审批不会重复扣减。
  • The requester cannot approve their own movement; --force leaves a chain row. · 申请人不能批准自己的动作；--force 会在链上留一行。
  • A blocked task writes no movement at all. · 被拦下的任务一行库存都不写。

Boundary

  • Prototype, not a WMS. No multi-warehouse network, no bin-level picking, no finance posting.原型，不是 WMS：不做多仓网络、货架位拣选、财务过账。
  • Environment thresholds are example values, unverified. Do not treat them as a compliance basis.环境阈值是示例值，未核证，不能当合规依据。
  • All numbers here are synthetic demo data.本页所有数字是合成演示数据。
  • Four eyes is enforced by actor strings — demo-grade. Production needs SSO/RBAC.四眼靠 actor 字符串，属演示级；生产要接 SSO/RBAC。
  • The hash chain proves local write order only: no external timestamp, no third-party witness.哈希链只证明本机写入顺序：没有外部时间戳，没有第三方见证。

Status

This is a local prototype: the kernel, panel and tests run on one machine against SQLite. The page you are reading is a capability statement plus a real snapshot — not an API. The warehouse kernel source is not public yet; the carbon half of the same kernel is public at github.com/erikcywong/shinae.work. 内核、面板与测试在本机跑；这一页是能力说明加真实快照，不是 API。 仓存内核源码暂未公开；同一内核的碳核证部分已公开。

Verification is a domain smoke test (allocation order, critic blocks, four eyes, idempotent movements, chain tamper) plus a headless render check of every panel view. 验证方式是领域测试（分配顺序、Critic 拦截、四眼、幂等、链篡改）+ 面板每个视图的无浏览器渲染检查。
