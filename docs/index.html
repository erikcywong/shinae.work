An agent OS for aeroponic coffee — and the carbon numbers behind it. 雾化咖啡的智能体操作系统，以及它背后的碳数字。

One sentence in, a Router decides whether it is work, a Worker runs it in its own directory with a bounded tool set, and the result returns to where it came from — the panel, or a Feishu chat. Every number lands in an append-only hash chain you can recompute. 一句话进来，Router 判断是不是该干的活，Worker 在自己的目录里带受限工具执行，结果回到它来的地方； 每个数字都落进可重算的追加式哈希链。

ROUTER / WORKER

Two layers, one writer. Only the Router creates Tickets; a Worker may only report.

双层架构，单一写者：只有 Router 能建工单，Worker 只能报告。

HASH-CHAINED LEDGER

Each run appends rows linked by SHA-256. A recompute is a new revision, never an edit.

每次核算追加一串 SHA-256 链行；重算是新版本，永不改写旧行。

FEISHU LOOP

Commands and questions in a chat open Tickets; cards and files come back to the same chat.

群里下指令 → 建单 → 卡片与附件回到同一条会话。

Run it

git clone https://github.com/erikcywong/shinae.work
cd shinae.work
python app/server.py            # zero dependencies, SQLite state
python app/server.py --live     # workers planned by a model

The panel asks for a local access token on first run (printed at startup, stored in var/auth.env). python tests/smoke.py node tests/ui_smoke.mjs

Second vertical: warehouse

The same kernel now runs coffee lots: green leaves FIFO, roasted leaves FEFO, expired and quarantined lots can never be picked, and a quantity only changes after plan → critic → dry-run → a second person → execute → verify. It works with Feishu rather than replacing it: cards and commands live in the chat, the rules and the hash chain live in the kernel. See the snapshot and the Feishu collaboration model → 同一个内核跑咖啡仓存：绿咖啡 FIFO、熟豆 FEFO，过期/隔离批次不出库；改数量必须过计划 → Critic → dry-run → 第二个人 → 执行 → 核验。 它与飞书是协作而非替代：卡片与指令在群里，规则与哈希链在内核里。

What it is not

  • Not a certified carbon system. The factor set is reference-grade and marked unverified; the boundary is cradle-to-gate. No external labels.
  • Not a generic agent framework. It is one deployment of the two-layer idea for coffee.
  • Not multi-tenant yet. One workspace, one operator, one token.
